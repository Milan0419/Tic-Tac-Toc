# Tic Tac Toe Web App

A responsive Tic Tac Toe game made using *HTML, **CSS, and **JavaScript*. This project offers a clean UI, win detection, and a playful user experience.

## Features

- Interactive 3x3 Tic Tac Toe board
- Real-time win/lose detection and display
- Reset functionality for new games
- Responsive web design 
- Friendly visual feedback with notification and images
- 2. Open index.html in your browser.
